# CPYOS feature matrix — Metalio E-INK4 Plus

Objective: every CPYOS feature that works on Read Pico must be usable on the
Plus and **verified on the device**, not just compiled.

Status legend: **V** verified on hardware (log/screenshot evidence),
**U** untested (needs a device pass), **B** blocked by an external condition,
**N/A** not applicable to this build.

Evidence paths are relative to this repository; screenshots/logs from the
2026-11-11 sessions live under `/tmp/soak6`, `/tmp/plus_*.log` on the bring-up
machine and are summarized here by their key lines.

## Bench console hooks (for scripted device tests)

`act` prints the current activity name, `ring <n>` moves an activity's selection,
`sel <n>` sets it absolutely, `confirm` activates it, `key <name>` sends a key,
`tap <x> <y>` taps logical coordinates. Storage: `sdwrite`, `sdstress <n>`
(write + full scan per round), `sdremount`, `sdpark` (opens a file, parks all
handles, restores, and verifies the stream continues at the same offset — the
light-sleep path without sleeping). JJWXC logs `state -> N` on every page
change.
