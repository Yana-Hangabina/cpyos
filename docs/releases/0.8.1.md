# 脆皮鸭 CPYOS 0.8.1

Read Pico `0.8.1-rp` · Metalio E-INK4 Plus `0.8.1-e4p`

## 新增功能

### 界面缩放

- 设置 → 显示 → **界面缩放**：100%（默认）到 125%，即时生效，随设置保存。
- 125% 下逐屏修正了四个主标签、设置、工具抽屉、找书、Wi-Fi 面板的排版：底栏不再被溢出内容遮挡，列表卡片的标题/副标题不再出框，滚动条落在面板圆角内。
- 阅读器、图片查看与睡眠画面保持物理像素语义（分页、选区和图片不受缩放影响）。

### Wi-Fi 稳定性

- 射频命令串行化：连接、断开、扫描、释放不会互相打断；失败时日志给出可读原因（`radio bring-up refused`、`join rejected`、`stored failure status` 等），不再只剩「通用故障」。
- 保存的网络可静默重连（待机、定时任务），退出页面即释放射频。
- 阅读/待机期间的空闲降频不再与面板推送互相打架。

### PDF

- PDF 引擎与固件解耦（契约 v2：版本、ABI、主机服务表、布局键）；应用重建不再让引擎失效。
- 本次应用代码增长把引擎的执行窗口移到了新地址，因此 **0.8.1 需要配对的新引擎**。升级后在 设置 → 应用与维护 → PDF 引擎 更新一次即可；网页刷机的完整安装包已自带该引擎。
- PDF 打开、重排、目录、书签、批注与导出行为不变。

### 阅读字体

- 阅读核心字体按字表分档发布：Read Pico 使用 3,500 常用字核心（约 642 KB，随数据分区），Metalio Plus 可用 8,105 字核心（约 1.64 MB）。
- 系统界面字族补全标点与符号（含中英混排常用的间隔号、书名号、破折号），含气泡、书名与作者名不再整串降级成小字号。
- 字体扩展包清单支持 tier 字段（FEXT2），设备可以分辨「完整 CJK / 完整 emoji」这类覆盖声明。

### 其它

- 电量胶囊每秒采样一次，不再长时间空白。
- 新增「下载完成」等文案；语言包为 1,879 键。

## 升级说明

- **0.8.0 及以后的设备可以直接 OTA**（应用 + 数据包）。0.7.0 及更早版本仍必须使用完整安装包。
- 本次更新了语言包与核心字体，两者都在数据分区：OTA 清单已包含它们；手工刷写请使用 `exp/flash_device.sh`，不要只写 app。
- Metalio Plus 通过 CloudZao 市场更新时只写应用分区，数据包请使用官网完整安装或设备内更新。

## 验证

- Read Pico 真机：`refresh_soak` 36/36；引擎加载 `code mapped at 0x42da0000` 且 `PDFMODTEST ok=1`；两页 PDF 打开并重排；界面缩放 100/125 逐屏截图核对。
- 发布前校验：`verify_release_artifacts.py --release`、数据清单与五个数据包头、`SHA256SUMS`。
