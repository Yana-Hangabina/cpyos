# 脆皮鸭 CPYOS 0.8.0（Metalio E-INK4 Plus）

版本 `0.8.0-e4p` · 首次发布

## 新增

- 适配 1216×684 墨水屏、触摸、三个侧键、电源键、4-bit SD、USB 串口与 U 盘、前光、扬声器与麦克风、触觉马达、电池计与充电状态、RTC、待机时钟与浅睡。
- 4G 已接入数据通路、SIM 状态与网络切换界面；本机未安装模块，实际联网待实机验证。
- 支持扬声器、麦克风和蓝牙音频；AI 语音、录音等依赖服务器或耳机的功能待实机验证。
- 前光支持亮度调节，并按厂商建议限制最高亮度。
- 提供书架、阅读器、PDF、浏览器、微信读书、晋江（闭源组件）、字体、WebDAV/Calibre、插件与游戏、计算器、阅读统计等完整应用。
- 电源支持电量百分比、充电状态页、待机时钟、浅睡和长按关机。
- CloudZao 设备绑定、资源推送和固件更新迁移到新 partner API（待实机验证）。

## 改进

- 修正前光电流映射、快速翻页与水波纹设置持久化、Wi-Fi 自动连接与内存占用、截图方向和阅读统计缺字。
- 设置、弹窗、等待卡、购买抽屉和阅读器面板的交互与视觉统一。

## 升级说明

- 首次通过 CloudZao 固件市场或官网完整安装，之后使用 CloudZao OTA。
- 首次使用设备资源前，需要在新的 partner API 中重新完成六位验证码绑定。
- 升级前建议备份 SD 卡和设备整片镜像；非中英文界面需要完整数据分区。
- CloudZao 首版需要平台审核；审核完成前设备可能查不到稳定版。
