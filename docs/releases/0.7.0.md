# 脆皮鸭 CPYOS 0.7.0

新增可下载的扩展字体，并让联网下载在内存紧张或网络不佳时更可靠。基于 0.6.2，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **扩展字体**：「设置 → 阅读 → 扩展字体」可以把完整 Emoji、扩展中文字体（含日文假名）和多语言文字包下载到 SD 卡。字体不写入固件，固件与 OTA 的下载体积保持不变；只占用所选字体的大小，随时可以删除。
- **缺字提示**：Wi-Fi 名称、书名等出现内置字体没有的字符时，首页或阅读器会提示安装合适的字体包。已安装的字体重启后自动生效。
- **安装管理**：每个字体包显示“已安装 / 可更新 / 未安装”；下载失败会说明原因（无 Wi-Fi、超时、校验失败等），可以直接重试或返回。

## 改进

- **联网更稳**：TLS 握手改用 PSRAM，内部内存紧张时也能完成检查更新和字体下载；刚连上 Wi-Fi 时的时间同步不再干扰网页与字体下载。
- **下载线路更短**：字体列表按 Pages → GitHub → 镜像依次尝试，字体文件复用刚成功的线路，每条线路有独立超时，不再因为某个镜像不可用而长时间等待。
- **下载可取消**：检查列表或下载字体时都可以随时取消，取消后不会留下不完整的文件。
- **网页阅读**：打开较大的网页前会释放已加载字体，避免页面缓冲分配失败。

## 升级说明

- 0.6.0 及以后可以直接在设备内 OTA；语言与资源包会随系统一并更新。
- 0.2.1 及更早版本请用官网网页刷机升级一次。
- 扩展字体是独立的可选下载，不计入固件或 OTA 数据包。

## English

Downloadable font packs, plus more reliable network downloads when memory or the network is tight. Based on 0.6.2, for **Read Pico (RDP-G01-W)**.

**New.** Settings → Reading → Font extensions downloads a full emoji font, an extended CJK font (including kana) or a multi-script font to the SD card. Fonts are not built into the firmware, so firmware and OTA download sizes are unchanged; each pack uses only its own space and can be removed at any time. When a Wi-Fi name, book title or page needs a glyph the built-in fonts do not have, Home or the reader offers the matching pack. Installed packs load again after a reboot. Every pack shows installed / update available / not installed, and a failed download names the cause (no Wi-Fi, timeout, failed check) with retry and back actions.

**Improved.** TLS handshakes now use PSRAM, so update checks and font downloads still work when internal memory is low; time sync right after joining Wi-Fi no longer interferes with web or font downloads. The font list tries Pages, then GitHub, then a mirror, and font files reuse the route that just worked, each with its own timeout. Font downloads can be cancelled at any time without leaving a partial file. The browser releases loaded fonts before opening a large page, avoiding page-buffer allocation failures.

**Upgrade.** 0.6.0 and newer can use device OTA directly; language and resource packs update together with the app. Devices on 0.2.1 or older still need the web flasher once. Font extensions are optional downloads and are not part of the firmware or OTA data packs.
