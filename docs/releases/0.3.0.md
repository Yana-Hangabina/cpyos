# 脆皮鸭 CPYOS 0.3.0

统一界面表面、可缩放中文字体与刷新性能。基于 0.2.3，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 重要变化

- **晋江客户端改为私有组件**：公共源码只保留通用接口与空桩，晋江相关实现不再随公共源码分发。发布固件仍包含完整功能，使用体验与 0.2.3 一致。

## 新增与改进

- **统一的弹窗、等待与提示**：加载、错误和确认使用同一套卡片与遮罩；确认框改为内联，不再跳整页；购买改为底部抽屉。
- **可缩放中文字体**：界面与正文统一到一套覆盖 8,105 个常用汉字与 GB2312 的字体，阅读字号 12–18pt 可选，不再出现生僻字让整行变小。
- **更清晰的显示**：正文使用 16 级灰度；界面图标、斜线、圆弧和圆角也做抗锯齿。
- **刷新更省电、更少闪烁**：键盘、列表、阅读器面板、游戏、待机时钟和手写首页使用局部刷新；残影清理改为局部矩形；完整刷新间隔可设置。
- **书签**：正文右上角实心书签角标，书签面板固定添加入口，行尾可删除。
- **功耗与唤醒**：Wi-Fi 用完后释放；面板空闲断电；阅读器短按电源键进入时钟待机，再按返回原页。

## 升级说明

- 语言包有变化，**本次需要完整安装或重刷数据分区**；只升级系统时英文与中文正常，其余语言会回退英文。
- 0.2.2 / 0.2.3 可直接在设备内 OTA；0.2.1 及更早版本请用官网网页刷机升级。

## English

Unified surfaces, a scalable Chinese font and better refresh. Based on 0.2.3, for **Read Pico (RDP-G01-W)**.

**Important.** The JJWXC client is now a private component. The public source keeps only the generic interface and inert stubs; release firmware still includes the full app, and user-visible behaviour is unchanged from 0.2.3.

**New and improved.** Loading, error and confirmation screens share one surface and scrim; confirms are inline and the purchase flow is a bottom drawer. One scalable Chinese font covers 8,105 common characters plus GB2312, with reader sizes 12–18 pt, so rare characters no longer shrink a whole line. Body text uses 16 gray levels and UI icons, lines, arcs and corners are antialiased. Partial refresh covers the keyboard, lists, reader panels, games, standby clock and home pages; ghost cleanup uses local rectangles and the full-refresh interval is configurable. Bookmarks gain a ribbon, a fixed add/remove strip and per-row delete. Wi-Fi is released when finished, panel rails power down when idle, and a short power press in the reader enters a clock standby that returns to the same page.

**Upgrade.** The language pack changed, so a **full install or data-partition reflash is required**; an app-only update keeps Chinese and English but other languages fall back to English. 0.2.2/0.2.3 can use device OTA; 0.2.1 and older need the website flasher once.
