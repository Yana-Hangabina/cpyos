# 脆皮鸭 CPYOS 0.3.0

统一表面系统、可缩放中文字体与刷新性能，基于 0.2.3。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 重要变化

- **晋江客户端改为私有组件**。公共仓库只保留 `src/booksource/` 的通用接口与空桩；晋江协议、存储、界面实现已移出，不随公共源码分发。带晋江 App 的固件由发布流水线在构建时引入私有组件，用户侧功能与 0.2.3 完全一致（书架、发现、搜索、购买、段评、缓存服务、阅读器目录操作都不变）。

## 新增与改进

- **统一的等待 / 消息 / 通知表面**：所有「加载中」改为同一张鸭子波浪进度卡，一次性提示走轻量 Toast，需要用户确认的错误走带 12.5% 遮罩的消息卡；确认框全部内联，不再跳整页。购买流程改为底部抽屉，输入支付密码时在同一抽屉内上抬。
- **圆角容器裁剪**：弹窗滚动条、卡片内的整行反色光标不再越出圆角轮廓。
- **可缩放中文字体**：UI 与正文统一到一套可缩放字族，覆盖《通用规范汉字表》8105 字 + GB2312 + 常用中英标点；首次启动把字体释放到 SD 卡，运行时流式读取，常驻 PSRAM 显著下降。12/14/16/18pt 均可选，不再出现「含生僻字整行变小」。
- **16 级文字抗锯齿**：正常阅读正文走 16 级灰度；UI 图标、斜线、圆弧与圆角在 16 级页面上也做覆盖度抗锯齿。
- **文字设置页修复**：离开页面不再卡死；新增 1 位 / 16 级预览开关；预览使用独立的字号与字形缓存预算，退出时释放。
- **刷新性能**：键盘、列表、阅读器面板、游戏、待机时钟面与手写首页改为列带刷新；残影清理默认改为局部矩形清理，阅读器全刷间隔可在设置中选择「随翻页 / 每分钟 / 固定页数」。
- **书签**：正文右上角实心书签角标，面板顶部固定「添加/移除书签」，行尾可删除。
- **功耗与唤醒**：Wi-Fi 用完后释放射频；面板高压轨空闲 8 秒断电；阅读器短按电源键进入时钟待机，再按返回原页。

## 升级说明

- 语言包键数有变化，**本次必须完整安装或重刷数据分区**（`pinyin.dat`、`web_pack.dat`、`hyphen.dat`、`i18n_pack.dat`、`emoji.dat`）。只刷 app 会退回英文界面。
- 0.2.2 / 0.2.3 可直接在设备内 OTA；0.2.1 及更早版本请用官网网页刷写升级。

## English

Unified surfaces, a scalable Chinese font and refresh-performance work, based on 0.2.3, for **Read Pico (RDP-G01-W)**.

**Important.** The JJWXC client is now a private component. The public repository keeps only the generic `src/booksource/` interface and inert stubs; the protocol, storage and UI implementation are no longer distributed with the public source. Release firmware is built with the private component, and the user-visible behaviour is unchanged from 0.2.3 (shelf, discover, search, purchase, paragraph comments, background cache service and reader TOC actions).

**New and improved.** One shared wait card / message card / toast surface with a 12.5% scrim and inline confirms; the purchase flow is a bottom drawer that rises for the payment keypad; rounded containers now clip their contents. A single scalable CJK family covers the 8105-character standard set and is released to the SD card on first boot and streamed afterwards. Reader text is rendered at 16 gray levels, and UI icons/lines/arcs get coverage anti-aliasing on 16-level pages. The text-settings page no longer freezes, gains a 1-bit/16-level preview, and uses a smaller glyph budget while previewing. Band refresh covers the keyboard, lists, reader panels, games, the standby clock face and the hand-written home pages; ghost cleanup defaults to a local rectangle and the full-refresh cadence follows the new setting. Bookmarks gain a solid corner ribbon, a fixed add/remove strip and per-row delete. Wi-Fi is released when a screen is done, the panel rails power down after 8 s idle, and a short power press in the reader enters a clock standby that returns to the same page.

**Upgrade.** The language pack's key count changed, so this release requires a **full install** (or a data-partition reflash). App-only OTA falls back to English. 0.2.2 and 0.2.3 can OTA in place; 0.2.1 and older need the web installer once.
