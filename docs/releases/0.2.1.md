# 脆皮鸭 CPYOS 0.2.1

修复网页升级可能“显示成功但设备仍运行旧系统”的问题。基于 0.2.0，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 修复

- **网页升级同时写入两个系统槽**：设备做过一次 OTA 后会从第二个系统槽启动，而网页刷机无法自动判断当前槽。此前的升级包只写第一个槽，可能出现“写入成功、版本没变”。
- 「从 CPYOS 升级」和仅系统升级现在都会写入两个系统槽以及数据包；首次安装仍按原方式写入。

## 升级说明

- 0.2.0 升到 0.2.1：数据包没有变化，设备内 OTA 只更新系统；网页升级请使用本版本的升级包。
- 0.1.x 升到 0.2.1：语言包有变化，中文与英文界面正常，其余语言需要完整安装或重刷数据分区。
- 首次安装或从 CrossMux 切换仍使用官网网页刷机。

## English

Fixes a web upgrade that could report success while the device still booted the old system. Based on 0.2.0, for **Read Pico (RDP-G01-W)**.

**Fix.** The web upgrade now writes both system slots. After one OTA the device boots from the second slot, which a browser cannot detect; the previous upgrade wrote only the first slot, so it could claim success without changing the running version. The upgrade and app-only packages now write both slots plus the data packs, while the first-install package keeps its original layout.

**Upgrade.** 0.2.0 to 0.2.1 keeps the data packs, so device OTA only updates the system; use this version's upgrade package in the browser. From 0.1.x the language pack changed: Chinese and English stay complete, while other languages need the full installer or a data-partition reflash. Use the website installer for a first install or when switching from CrossMux.
