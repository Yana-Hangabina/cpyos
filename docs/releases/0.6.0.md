# 脆皮鸭 CPYOS 0.6.0

设备更新开始同时更新语言与资源包，升级后不再需要重新刷写数据分区。基于 0.5.0，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **更新时一并更新数据包**：设备只下载与当前版本不同的语言包、网页资源、拼音、断词和 emoji 包，校验通过后才写入；系统与数据都成功后才切换。
- **旧语言包兼容**：语言包新增文案时，旧语言包仍可继续使用，新增部分暂时显示英文，不再因为语言包版本不同而整体失效。
- **数据包重试提示**：如果数据包下载失败，设备继续用旧数据启动，并在首页提示重试更新。
- **只更新数据包**：系统已是最新但资源包不同时，更新页会只更新语言与资源包。

## 升级说明

- 0.5.0 可以直接在设备内 OTA；重启后再进入一次「设置 → 系统 → 检查更新」即可补全语言与资源包。
- 0.6.0 及以后更新时会自动同时更新系统与数据包。
- 0.2.1 及更早版本请用官网网页刷机升级一次。
- 本次语言包有变化，但不再需要完整安装。

## English

Device updates now include the language and resource packs, so a language change no longer requires reflashing the data partition. Based on 0.5.0, for **Read Pico (RDP-G01-W)**.

**New.** OTA downloads only the language pack, web resources, pinyin, hyphenation and emoji pack that differ from the current device, verifies each one before writing, and switches only after both the system and the data succeed. Older language packs remain usable when new strings are added; the appended text falls back to English instead of disabling all languages. If a data pack fails, the device keeps the old pack and Home offers a retry. When the system is current but a pack differs, the update page installs the packs only.

**Upgrade.** 0.5.0 can use device OTA; after the reboot, open Settings → System → Check updates once to fetch the full language and resource packs. 0.6.0 and newer update both automatically. Devices on 0.2.1 or older still need the website flasher once. This release changes the language pack but no longer needs a full install.
