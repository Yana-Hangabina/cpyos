# 脆皮鸭 CPYOS 0.6.0

OTA 现在会同时更新数据包，语言包新增文案不再要求完整安装；首页会在数据包回退时提示重试。基于 0.5.0，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **OTA 更新数据包**：设备读取发布目录里的 `readpico-packs.txt`，只下载与当前分区不同的语言包、网页包、拼音、断词和 emoji 包。每个包先下载到 SD 临时文件并校验 SHA-256，通过后才擦写，写入后回读校验；app 与数据都成功后才切换启动槽。
- **旧语言包兼容**：语言包按“键集合前缀”兼容，0.5.0 的 1675 键语言包可在 0.6.0 上继续使用；新增键临时回退英文，不再因为键数变化让 33 种语言整体失效。
- **首页重试提示**：如果数据包下载失败，设备会继续用旧包启动；当界面使用打包语言时，首页自动弹出提示，可直接进入“检查更新”重试。
- **只更新数据包**：“检查更新”在 app 已是最新但数据包不同时，显示“语言与资源包”，只更新数据分区。
- **章评**：阅读器的“更多”/经典菜单可以查看整章评论，支持点赞、回复和翻页；首屏自动缓存，断网也能打开。

## 改进

- README 与官网只描述可用功能，不再展开站点内容处理细节。
- 章评、单行阅读器标题栏、工具抽屉三列、超时睡眠画面、Wi-Fi 图标与等待卡等界面修正随 0.5.0 一并提供。

## 升级说明

- 0.5.0 可以直接在设备内 OTA 到 0.6.0：app 更新后旧语言包仍可用，新增文案暂时显示英文。**升级完成后进入“设置 → 系统 → 检查更新”一次**，即可补全语言与资源包（只更新数据分区）。
- 0.6.0 以后的版本在 OTA 时会自动更新 app 与数据包，不需要额外操作。
- 0.2.1 及更早版本仍请用官网网页刷机升级一次。
- 本次语言包 1781 键 / 约 345 KB，数据包布局不变；只有分区表或包格式破坏性变化才需要完整安装。

## English

OTA now updates the data packs as well; language-pack changes no longer require a full install, and Home offers a retry when a pack falls back. Based on 0.5.0, for **Read Pico (RDP-G01-W)**.

**New.** Device OTA reads `readpico-packs.txt` next to the release manifest and downloads only packs whose SHA-256 differs from the partition. Each pack is downloaded to an SD temporary file, verified, written, and read back before the new app slot is selected. Older language packs are accepted when their keys are a prefix of the current set; the 1675-key 0.5.0 pack works on this 1781-key image and appended keys fall back to English. When a pack download fails, the device keeps the old pack, boots the new app, and Home prompts for a retry. Check updates can also install packs only when the app is already current. Chapter comments are available from the reader menu.

**Upgrade.** 0.5.0 can use device OTA directly. After the reboot, open Settings → System → Check updates once to fetch the full language and resource packs; later releases update both automatically during OTA. Devices on 0.2.1 or older still need the web flasher once. The data partition layout is unchanged; only a partition-table or pack-format break requires a full install.
