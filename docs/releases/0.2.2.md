# 脆皮鸭 CPYOS 0.2.2

OTA 清单可达性、升级速度与旧版升级路径修复，基于 0.2.1。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 修复

- **设备 OTA 清单不再依赖 GitHub Pages**。部分网络（含本次验证网络）无法访问 `yana-hangabina.github.io`，设备会停在 `Release check fetch failed`，完全无法发现新版本。
- 清单地址改为 **GitHub Release 的 `latest` 资产**，经 `gh-proxy.com` 读取：
  `https://gh-proxy.com/https://github.com/Yana-Hangabina/cpyos/releases/latest/download/readpico-ota.json`
- 下载镜像扩展为 **7 个**：`gh-proxy.org`、`git.yylx.win`、`ghfast.top`、`gh-proxy.com`、`github.tbap.top`、`gh.dpik.top`、`ghproxy.net`。设备逐个探测首字节与 32 KB 吞吐，选择可用的最快线路。
- **OTA 全程持有 240 MHz 锁**：此前 OTA 没有触摸输入，电源管理会把 CPU 降到 80 MHz，叠加 2 KB TLS 记录和逐块 flash 写入后，实测只有约 4 KB/s。0.2.2 在检查与下载/安装期间保持 240 MHz，显著缩短升级时间。
- 发布清单的固件 URL 使用 `gh-proxy.com` 前缀；0.2.2 仍会剥离前缀并探测全部镜像。

## 升级说明

- ★ **0.2.1 及更早版本请使用官网网页刷写升级到 0.2.2 或更新版本**，不要依赖设备内 OTA：
  这些版本的 OTA 清单仍在 GitHub Pages，部分网络无法访问，设备会一直显示检查更新失败或极慢。
  官网「从 CPYOS 升级」/完整安装包会同时写 app0、app1 和五个数据包；升级一次后即可正常使用设备 OTA。
- **0.2.2 及以后**：设备 OTA 走镜像清单，正常更新；数据包未变化时只写 app 分区。
- 中文界面在 app-only OTA 后完整；其余 33 种语言需要完整包或数据分区升级。

## English

OTA manifest reachability, upgrade speed and old-version upgrade-path fix, based on 0.2.1, for **Read Pico (RDP-G01-W)**.

**Fix.** Device OTA no longer depends on GitHub Pages. Some networks (including the one used for this verification) cannot reach `yana-hangabina.github.io`, leaving the device at `Release check fetch failed` with no way to discover an update. The manifest now comes from the GitHub Release `latest` asset through `gh-proxy.com`:
`https://gh-proxy.com/https://github.com/Yana-Hangabina/cpyos/releases/latest/download/readpico-ota.json`
The download mirror list grows to seven routes (`gh-proxy.org`, `git.yylx.win`, `ghfast.top`, `gh-proxy.com`, `github.tbap.top`, `gh.dpik.top`, `ghproxy.net`); the device probes first-byte and 32 KB throughput and picks a working route. OTA now holds a **240 MHz lock** for the whole check and download/flash: without touch input the power manager used to drop to 80 MHz, and with 2 KB TLS records plus per-chunk flash writes that measured only about 4 KB/s. The published firmware URL uses the `gh-proxy.com` prefix; 0.2.2 still strips it and probes every mirror.

**Upgrade notes.** ★ **Versions up to 0.2.1 should use the website flasher to install 0.2.2 or newer**, not device OTA: their manifest still lives on GitHub Pages, which some networks cannot reach, so device updates fail or crawl. The website's "Upgrade from CPYOS" / full installer writes app0, app1 and the five data packs; after that one flash, device OTA works normally. From 0.2.2 on, device OTA uses the mirror-hosted manifest; when the data packs are unchanged it writes only the app partition. The Chinese UI stays complete after an app-only OTA; the other 33 packed languages need the full installer or a data-partition upgrade.
