# 脆皮鸭 CPYOS 0.2.2

让设备更新不再依赖 GitHub Pages，并修复 OTA 下载过慢的问题。基于 0.2.1，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 修复

- **更新检查不再依赖 GitHub Pages**：部分网络无法访问原来的更新清单地址，设备会一直显示检查失败。清单改为从 GitHub Release 读取，并可通过镜像访问。
- **下载线路增加**：提供多条备用线路，自动选择可用且较快的一条。
- **OTA 全程保持高性能**：下载与写入期间不再降频，升级速度明显提升。
- **官网提示**：旧版本（0.2.1 及更早）请用网页刷机升级一次，之后即可正常使用设备内更新。

## 升级说明

- ★ **0.2.1 及更早版本请用官网网页刷机升级到 0.2.2 或更新版本**，不要依赖设备内 OTA：这些版本的更新清单仍在 GitHub Pages，部分网络无法访问。
- 0.2.2 及以后可以直接在设备内 OTA；数据包没有变化时只更新系统。
- 中文界面完整；其余语言需要完整安装或重刷数据分区。

## English

Device updates no longer depend on GitHub Pages, and OTA downloads are much faster. Based on 0.2.1, for **Read Pico (RDP-G01-W)**.

**Fixes.** The update manifest now comes from the GitHub Release and can be reached through mirrors, so networks that cannot open the old Pages address no longer fail every check. Several backup download routes are available and the device picks a working, fast one. OTA keeps full CPU speed during download and flashing, which makes updates noticeably faster. The website now tells users on 0.2.1 and older to upgrade once with the web flasher.

**Upgrade.** ★ **Devices on 0.2.1 or older should use the website flasher to install 0.2.2 or newer**, not device OTA, because their manifest still lives on GitHub Pages. From 0.2.2 on, device OTA works normally and only updates the system when the data packs are unchanged. The Chinese UI stays complete; other languages need the full installer or a data-partition reflash.
