# 脆皮鸭 CPYOS 0.6.1

修复“检查更新卡住或失败”，并让更新清单自动走可用的线路。基于 0.6.0，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 修复

- **检查更新不再被单条线路拖住**：依次尝试多条可用线路，每条都有超时上限；失败后正常结束并提示，而不是一直等待。
- **备用线路**：GitHub、镜像与 Pages 之间自动回退，某条线路不可用时不再阻塞整个检查。
- **数据包走同一条线路**：语言与资源包使用刚成功的线路，仍然只下载有变化的包。
- **提示更明确**：连接 Wi-Fi 不代表一定能访问 GitHub 或镜像；全部线路失败时会明确显示失败。

## 升级说明

- 0.6.0 可直接在设备内 OTA；数据包与 0.6.0 相同。
- 0.2.1 及更早版本请用官网网页刷机升级一次。

## English

Fixes update checks that could hang or fail, and routes the manifest through a working line. Based on 0.6.0, for **Read Pico (RDP-G01-W)**.

**Fixes.** The check tries several routes in turn with a timeout on each, so one dead route no longer blocks it; it ends with a clear failure instead of waiting indefinitely. GitHub, mirrors and Pages fall back to each other, and the data packs reuse the route that just worked while still downloading only changed packs. The failure text also notes that a connected Wi-Fi network does not guarantee access to GitHub or a mirror.

**Upgrade.** 0.6.0 can use device OTA; the data packs are unchanged from 0.6.0. Devices on 0.2.1 or older need the website flasher once.
