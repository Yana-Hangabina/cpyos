# 脆皮鸭 CPYOS 0.5.0

章评、单行阅读器标题栏和一轮界面细节修正，基于 0.4.0。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **章评**：阅读器的「更多」面板和经典菜单新增「章评」，查看整章评论。支持点赞、回复和翻页；首屏自动缓存，之后断网也能打开。不提供“写新章评”。
- 章评与段评共用同一个面板和 JJD1 缓存，缓存文件是 `comments/<chapterId>-0.bin`；「刷新」是唯一显式联网入口。

## 改进

- **阅读器单行标题栏**：不再常驻第二行字号，进度百分比移到页脚波浪条右端，正文多出一整行。
- **工具抽屉三列**：「晋江文学城」等 5 个汉字的应用名完整显示，不再截断。
- **超时休眠**：自动休眠改用正常睡眠画面，避免把首页或阅读页留在屏上被误认为卡死。
- **Wi-Fi 与等待卡**：信号格、锁图标在右边距内对齐；等待卡按内容收缩。
- **emoji**：子集扩到 250 个码位，覆盖常见 Wi-Fi 名称与书名；切换字号失败时保留旧字形。
- **设置与购买**：选择器行尾箭头不再显示方框；弹窗文字轴与底部留白修正；禁用主按钮、密码摘要完成对齐。

## 升级说明

- 语言包新增章评文案，键数从 1672 变为 1675，**必须完整安装或重刷数据分区**。只刷 app 分区时英文与中文界面正常，其余 33 种语言会回退英文，直到重刷数据分区。
- 0.2.1 及更早版本请用官网网页刷写升级一次；0.2.2 及更新版本可直接在设备内 OTA。

## English

Chapter comments, a one-line reader header and a round of UI detail fixes, based on 0.4.0, for **Read Pico (RDP-G01-W)**.

**New.** Chapter comments in the reader's More panel and classic menu: read the whole chapter's comment list, like, reply and page through it. The first page is cached automatically and opens offline afterwards; posting a new chapter comment is not offered. Chapter and paragraph comments share one panel and the JJD1 cache at `comments/<chapterId>-0.bin`; Refresh is the only explicit network action.

**Improved.** The reader header is now a single line and the book percentage sits at the end of the footer wave, regaining one text line. The tool drawer uses three columns so five-character app names such as 晋江文学城 are no longer truncated. A timeout sleep now shows the sleep screen even when Quick Resume is selected. Wi-Fi signal/lock icons are aligned inside the right margin and wait cards shrink to their content. The emoji subset grows to 250 codepoints and a failed font-size change keeps the previous face instead of dropping emoji. Picker chevrons no longer render as empty boxes; popup text axes, disabled primary buttons and purchase summary sizes are aligned.

**Upgrade.** The language pack gained chapter-comment strings (1672 to 1675 keys), so a **full install or data-partition reflash is required**. App-only OTA keeps English and Chinese working, but the other 33 languages fall back to English until the partition is reflashed. 0.2.1 and older need the web installer once; 0.2.2 and newer can use device OTA.
