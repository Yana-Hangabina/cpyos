# 脆皮鸭 CPYOS 0.5.0

新增章评，阅读器标题栏更紧凑，并修正一轮界面细节。基于 0.4.0，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **章评**：阅读器的「更多」菜单和经典菜单可以查看整章评论，支持点赞、回复和翻页。首屏自动缓存，之后断网也能打开；不提供发表新章评。

## 改进

- **阅读器标题栏**：改为单行，进度百分比移到页脚波浪条右侧，正文多出一行。
- **工具抽屉**：改为三列，「晋江文学城」等较长的应用名可以完整显示。
- **自动休眠**：到时显示正常的睡眠画面，不再把首页或阅读页留在屏上。
- **Wi-Fi 与等待卡**：信号和锁图标在右边距内对齐；等待卡按内容收缩。
- **emoji**：补充常见 Wi-Fi 名称和书名中的字符。
- **设置与购买**：修正选择器行尾箭头、弹窗间距和购买按钮的对齐。

## 升级说明

- 语言包新增章评文案，**需要完整安装或重刷数据分区**；只升级系统时英文与中文正常，其余语言会回退英文。
- 0.2.2 及以后可直接在设备内 OTA；0.2.1 及更早版本请用官网网页刷机升级一次。

## English

Chapter comments, a tighter reader header and a round of UI fixes. Based on 0.4.0, for **Read Pico (RDP-G01-W)**.

**New.** Chapter comments in the reader's More and classic menus show the whole chapter's comments, with likes, replies and paging. The first page caches automatically and opens offline; posting a new chapter comment is not offered.

**Improved.** The reader header is now one line, with the book percentage at the end of the footer wave, regaining a line of text. The tool drawer uses three columns so longer app names such as 晋江文学城 fit. A timeout sleep shows the normal sleep screen instead of leaving a page on screen. Wi-Fi signal/lock icons align inside the right margin and wait cards shrink to fit. Emoji cover more characters used in Wi-Fi names and book titles. Picker chevrons, popup spacing and purchase button alignment were corrected.

**Upgrade.** The language pack gained chapter-comment text, so a **full install or data-partition reflash is required**; app-only keeps Chinese and English, while other languages fall back to English. 0.2.2 and newer can use device OTA; 0.2.1 and older need the website flasher once.
