# 脆皮鸭 CPYOS 0.4.0

新增网页阅读，应用集中到一个工具抽屉，弹窗表面更轻。基于 0.3.0，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **网页阅读**：在「我的 → 工具」打开浏览器，输入网址后抓取正文，按当前阅读字号和灰度重新排版。支持页面内链接、翻页、页面菜单、书签和访问历史。
- **中文网页与压缩页面**：自动识别 GBK / GB18030 / UTF-16，并兼容常见的 gzip / deflate 页面。
- **HTTPS 与 HTTP**：两种地址都能打开，明文页面会标注不安全。浏览器不校验证书，请在可信网络中使用。
- **统一工具抽屉**：浏览器、微信读书、晋江、游戏与工具集中到「我的 → 工具」，显示/隐藏仍由应用可见性设置控制。

## 改进

- **弹窗更轻**：遮罩改为淡化被覆盖的页面，弹窗更突出；16 级页面不再出现大片灰色。
- **边框统一**：等待卡、消息卡、选项弹窗和确认框使用同一条实线描边，圆角容器内的内容不再越界。

## 升级说明

- 语言包新增网页阅读文案，**建议完整安装或重刷数据分区**；只升级系统时英文与中文正常，其余语言会回退英文。
- 0.3.0 及以后可先尝试设备内 OTA；0.2.1 及更早版本请用官网网页刷机升级一次。

## English

A reading browser, one tool drawer and lighter modal surfaces. Based on 0.3.0, for **Read Pico (RDP-G01-W)**.

**New.** The browser in My → Tools fetches a page and re-typesets its body at the current reading size and gray level. It supports in-page links, paging, a page menu, bookmarks and history. Chinese pages in GBK / GB18030 / UTF-16 and gzip/deflate pages are handled automatically. HTTPS and plain HTTP both open, with an explicit insecure marker for HTTP; certificates are not verified, so use a trusted network. Apps and tools now live in one drawer, still controlled by app visibility.

**Improved.** The modal scrim now fades the covered page so the popup stands out, and 16-level pages no longer show a large gray block. Wait, message, option and confirm surfaces share one solid border, and rounded containers clip their contents.

**Upgrade.** The language pack gained browser text, so a **full install or data-partition reflash is recommended**; app-only keeps Chinese and English, while other languages fall back to English. 0.3.0 and newer can try device OTA; 0.2.1 and older need the website flasher once.
