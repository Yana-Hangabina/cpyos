# 脆皮鸭 CPYOS 0.4.0

网页阅读、单一工具抽屉与更轻的弹窗表面，基于 0.3.0。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **网页阅读 App（浏览器）**：在「我的 → 工具」打开浏览器，输入网址后抓取页面并提取正文，按当前阅读字号与 16 级灰度重新排版，而不是缩放整页。支持页面内链接、翻页、页面菜单、书签与访问历史（可删除/清空）、最近访问和离线错误卡。
- **中文网页**：自动识别 GBK / GB18030 / UTF-16，gzip 与 deflate 压缩容错；不支持 JavaScript、表单和图片，依赖脚本渲染的站点可能只能取到导航文字。
- **HTTPS 与 HTTP**：两种地址都可以打开，明文 HTTP 会在页面上标注不安全；浏览器仍不校验证书与主机名，请使用可信网络。
- **单一工具抽屉**：浏览器、微信读书、晋江、游戏与工具统一进入「我的 → 工具」的四列应用网格；显示/隐藏仍由「我的 → 设置 → 应用可见性」控制，原有持久化位不变。

## 改进

- **弹窗遮罩改为褪色**：遮罩不再加黑点或平灰，而是保留四分之一墨迹、其余恢复为白。被覆盖页面变成浅淡底图，弹窗卡片与实线边框承担视觉焦点；16 级页面不再出现大片灰，驱动像素与残影都明显减少。
- **弹窗边框统一**：等待卡、消息卡、选项弹窗与内联确认共用同一条 2 px 实线描边；圆角容器内的滚动条与整行反色光标会被裁到圆角之内。

## 升级说明

- 语言包新增浏览器文案，键数有变化，**建议完整安装或重刷数据分区**。只刷 app 分区时英文与中文界面正常，其余 33 种语言会回退英文，直到重刷数据分区。
- 0.3.0 及更新版本可以先尝试设备内 OTA（只写 app 分区）；0.2.1 及更早版本请用官网网页刷写升级一次，不要依赖设备内 OTA。

## English

A reading browser, one tool drawer and lighter modal surfaces, based on 0.3.0, for **Read Pico (RDP-G01-W)**.

**New.** Browser in My > Tools fetches a URL and re-typesets the extracted body at the current reading size and 16 gray levels instead of shrinking the whole page. It supports in-page links, paging, a page menu, bookmarks and history (delete or clear), recent pages and an offline error card. Chinese pages are auto-detected as GBK / GB18030 / UTF-16 and gzip/deflate are tolerated; JavaScript, forms and images are not supported, so script-rendered sites may only expose navigation text. HTTPS and plain HTTP both open, with an explicit insecure marker for HTTP; server certificates are still not verified, so use a trusted network. Apps now live in one four-column tool drawer grid, and app visibility keeps the existing persisted bits.

**Improved.** The modal scrim now fades the covered page (one pixel in four keeps its ink) instead of adding black or a flat gray wash; the page becomes a pale backdrop, the modal card and its outline carry the focus, and 16-level pages no longer drive a large gray slab or ghost it. Wait cards, message cards, option popups and inline confirms share one 2 px solid outline, and rounded containers clip their scrollbars and reverse-video rows.

**Upgrade.** The language pack gained browser strings and its key count changed, so a **full install or data-partition reflash is recommended**. App-only OTA keeps English and Chinese working, but the other 33 languages fall back to English until the partition is reflashed. 0.3.0 and newer can try device OTA first; 0.2.1 and older need the web installer once.
