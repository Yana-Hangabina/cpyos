# 脆皮鸭 CPYOS 0.2.0

统一字体与阅读排版、PDF 标注、格式扩展，以及晋江段评的后台缓存。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 字体与阅读

- 系统 UI、书名/作者、晋江 App 与阅读正文统一到一套**可缩放 CJK 字族**：覆盖《通用规范汉字表》8,105 字与 GB2312，生僻字不再整串掉到 8pt 或显示方框。
- 字体包压缩后随固件写入，首次启动释放到 SD 并由阅读器流式读取；不再常驻一份 2.5 MB 的 PSRAM 缓冲。
- 新增 **UI 字号**（紧凑/标准/大/特大）与阅读字号 **10–34pt**；12/14/16/18pt 共用同一字族，不再因缺字切换字号。
- 文字与 UI 图形走 **16 级灰度 + 4-bit 覆盖度**：斜线、圆角、图标和反色文字都有抗锯齿；B/W 阈值回到 50%。
- 快速翻页保持 1-bit/DU，正常阅读可开启 16 级文字；阅读器内可用 `CMD:FONTDEMO` 同屏对比四种渲染。

## 阅读器与书籍

- **PDF 标注**：高亮、页内笔记、书签/笔记合并面板。
- 新增 **CBZ** 与 **FB2** 阅读；EPUB/TXT 之外支持静态 GIF 首帧。
- 点击区域可自定义（左右/上下/九宫格与边带），滑动删除书架条目，页面可底部对齐。
- 递归词典、CJK 断行修正、CSS `inherit`、NBSP/两端对齐与分页 LUT 内存修复。
- 阅读器首次手势提示只出现一次，任何输入都会关闭并持久化。

## 晋江文学城

- **段评正文后台缓存服务**：入队即开始；任意非阅读器界面进入待机、Wi-Fi 恢复或用户恢复时继续；可在缓存队列页暂停/恢复/清空。
- 主界面顶部显示状态图标：缓存中、暂停、已完成；已完成在第一次打开该书时清除。
- 阅读时只保留段评面板内预取；打开阅读器会暂停后台服务并释放射频，退出后自动恢复。
- 失去 Wi-Fi 时最多等待 60 秒，随后进入 10 分钟冷却，不空转重试；有已保存网络时静默连接。
- 新增「作者有话说」缓存、段评点赞/回复/发表、章节尾图标与购买入口。
- 成品 EPUB 与章节正文改用设备密钥 **AES-256-GCM v2** 加密，旧 v1 缓存自动迁移。

## 系统与功耗

- 修复待机「鸭子+时钟」假死：启动窗口中的排队页面不再覆盖首页。
- 开机阶段计时（boot/board/sd/stores/panel/splash/frame）与崩溃页的「上次停在」提示。
- 阅读器 Standby 返回原页；Wi-Fi 释放、8 秒高压轨空闲断电、电池日志与网络状态探针。
- 待机时钟面、键盘、设置、书库、游戏与阅读器面板使用列带/局部刷新；16 灰阶页面切换不再整屏闪。
- `freeink-sdk` 补丁更新到 30 个文件（CKV 原子帧启动、区段刷新、列带掩码、电源与 SD 降频）。

## 安装与升级

- 数据分区现有 **五个** blob：`pinyin.dat`、`web_pack.dat`、`hyphen.dat`、`i18n_pack.dat`、`emoji.dat`。
- **语言包键数与译文有变化**。中文与英文内嵌在固件里，所以 app-only OTA 后中文界面仍然完整；其余 33 种打包语言会回退英文，需用「从 CPYOS 升级」或完整安装包重写数据分区。
- `web_pack.dat`、拼音、断词与 emoji 包与 0.1.2 兼容，app-only OTA 不影响文件传输、输入与断词。
- 首次安装 / 从 CrossMux 切换仍使用网页刷机的「首次安装 / 恢复」；设备 OTA 只写 app 分区。

## English

One scalable CJK family, PDF annotations, more book formats, and background JJWXC paragraph-comment caching for **Read Pico (RDP-G01-W)**.

**Type and reading.** UI, book metadata, the JJWXC app and body text now share one scalable CJK family covering 8,105 standard Chinese characters plus GB2312, so rare characters no longer drop to 8 pt or render as boxes. The compressed face ships in the firmware, is released to SD on first boot and streamed from there instead of holding a 2.5 MB PSRAM copy. UI scale (Compact/Standard/Large/XL) and reader sizes 10–34 pt are selectable, and 12/14/16/18 pt share the same face. Text and UI graphics use 16-level gray with 4-bit coverage, giving antialiased diagonals, rounded corners, icons and inverted labels; the B/W threshold returns to 50%. Fast page turns keep 1-bit/DU, normal reading can use 16-level text, and `CMD:FONTDEMO` compares four render paths on one screen.

**Reader and books.** PDF highlights, per-page notes and a combined bookmarks/notes panel. CBZ and FB2 are supported, plus the first frame of static GIFs. Tap zones are configurable, shelf rows can be swiped away, pages can align to the bottom, and the dictionary supports recursive lookup. CJK line breaking, CSS `inherit`, NBSP/justify and the page-index LUT memory cost were fixed. The first-run gesture hint appears once and closes on any input.

**JJWXC.** Paragraph-comment bodies cache in the background: enqueue starts the queue, any non-reader standby or Wi-Fi return continues it, and the queue page can pause, resume or clear it. The main title bar shows running/paused/done badges, and Done clears when that book is first opened. Reading keeps only the in-panel prefetch; opening the reader pauses the service and releases the radio, and leaving resumes it. With no Wi-Fi the service waits up to 60 s, then cools down for 10 minutes instead of spinning. Author notes, comment likes/replies/posts, chapter-tail badges and purchase entries were added. Cached EPUBs and chapter bodies now use device-bound AES-256-GCM v2, with automatic v1 migration.

**System and power.** Fixed the standby zombie state where a queued page replaced Home during boot. Added boot-stage timings and a "last boot stopped at" line on the crash page. Reader standby returns to the same page; radio release, 8 s HV-rail idle-off, battery logging and network probes are included. Standby clock, keyboard, settings, library, games and reader panels use banded/partial refresh, and 16-level page switches no longer flash the whole panel. The `freeink-sdk` patch is now 30 files (atomic frame start, area refresh, band masks, power and SD clock fallback).

**Install and upgrade.** The data partition now holds five blobs: `pinyin.dat`, `web_pack.dat`, `hyphen.dat`, `i18n_pack.dat` and `emoji.dat`. The language pack's key count and text changed. Chinese and English are embedded in the firmware, so an app-only OTA keeps the Chinese UI complete; the other 33 packed languages fall back to English until the data partition is rewritten with the upgrade or full installer. The web, pinyin, hyphenation and emoji packs remain compatible with 0.1.2.
