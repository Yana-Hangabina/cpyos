# 脆皮鸭 CPYOS 0.2.0

统一中文字体与阅读排版，新增 PDF 标注、更多书籍格式和段评后台缓存。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **统一中文字体**：界面、书名、正文与晋江 App 共用一套可缩放中文字体，覆盖 8,105 个通用规范汉字和 GB2312，生僻字不再变小或显示方框。界面字号与阅读字号（10–34pt）可分别设置。
- **更清晰的文字与界面**：正文和界面图形使用 16 级灰度与抗锯齿，斜线、圆角、图标和反白文字边缘更平滑。
- **PDF 标注**：支持高亮、页内笔记和书签/笔记面板。
- **更多格式**：新增 CBZ、FB2，并支持静态 GIF 首帧。
- **阅读操作**：点击区域可自定义，书架条目可滑动删除，页面可底部对齐，词典支持递归查询。
- **晋江段评后台缓存**：段评正文可在后台排队下载，离开阅读器或连接 Wi-Fi 后自动继续，队列页可暂停、恢复或清空；主界面显示缓存状态。
- 晋江新增「作者有话说」缓存、段评点赞/回复/发表和章节购买入口。

## 修复与改进

- 修复待机时钟画面“按电源键无反应”的问题。
- 崩溃报告页记录重启原因与上次启动阶段。
- 阅读器短按电源键进入时钟待机，再按返回原页。
- Wi-Fi 用完后释放，面板高压轨空闲断电，降低待机功耗。
- 键盘、列表、设置、书库、游戏与阅读器面板改为局部刷新，减少整屏闪烁。

## 升级说明

- 语言包内容有变化。中文与英文内嵌在固件里，只升级系统时中文界面完整；其余 33 种语言需要完整安装或重刷数据分区。
- 首次安装或从 CrossMux 切换请使用官网网页刷机。

## English

One consistent Chinese typeface, clearer text, PDF annotations, more book formats and background comment caching, for **Read Pico (RDP-G01-W)**.

**New.** One scalable Chinese typeface now covers the UI, book metadata, body text and the JJWXC app, including 8,105 standard characters plus GB2312, so rare characters no longer shrink or show as boxes. UI size and reading size (10–34 pt) are separate. Text and UI graphics use 16 gray levels with antialiasing. PDF highlights and per-page notes, CBZ/FB2 and the first frame of static GIFs are supported. Tap zones are configurable, shelf rows can be swiped away, and pages can align to the bottom. JJWXC paragraph comments can cache in the background, continue after leaving the reader or reconnecting Wi-Fi, and be paused, resumed or cleared; the main screen shows the status. Author notes, comment likes/replies and chapter purchase entries were added.

**Fixes.** A standby clock screen that ignored the power button, a crash page that now records the reset reason and boot stage, a short power press that opens a clock standby and returns to the same page, Wi-Fi and panel-rail power-down, and partial refresh across the keyboard, lists, settings, library, games and reader panels.

**Upgrade.** The language pack changed. Chinese and English are built in, so an app-only update keeps the Chinese UI complete; the other 33 languages need the full installer or a data-partition reflash. Use the website installer for a first install or when switching from CrossMux.
