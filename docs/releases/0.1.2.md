# 脆皮鸭 CPYOS 0.1.2

设备 OTA 的国内下载加速。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 改动

- OTA 固件改为从 **GitHub Release 资产**下载，不再走 GitHub Pages（实测 Pages 在国内约 9 KB/s，6.8 MB 需要约 13 分钟）。
- 内置 **`ghfast.top`** 与 **`gh-proxy.com`** 两个 GitHub 镜像；升级时先各取 32 KB 测速，选择吞吐最高的一条线路再下载完整固件。测速失败自动回退，不会因为某个镜像不可用而卡住。
- 发布清单里的固件地址本身指向镜像（`https://gh-proxy.com/https://github.com/...`），所以 **0.1.1 及更早的固件无需升级到这个版本也能直接使用镜像加速**；0.1.2 会识别并剥离该前缀，再在直连与两个镜像之间择优。
- 新增串口诊断命令 `CMD:OTAPROBE`：在已联网的 OTA 页面上发送它，会打印三条线路的测速结果与最终选择（需要 `ENABLE_SERIAL_LOG` 构建）。

数据分区没有变化，**可以直接 OTA，不需要重刷数据包**。

## 安装与升级

设备 OTA：设置 → 系统 → 检查更新。首次安装 / 从 CrossMux 切换仍使用网页刷机的「首次安装 / 恢复」。

网页刷机：[yana-hangabina.github.io/cpyos](https://yana-hangabina.github.io/cpyos/#install)

## English

OTA downloads now use the GitHub release asset instead of GitHub Pages (Pages measured ~9 KB/s from mainland China, about 13 minutes for 6.8 MB). The firmware probes **ghfast.top** and **gh-proxy.com** with a 32 KB sample, then downloads through the fastest route and falls back if a mirror is unreachable. The release manifest itself advertises a mirror-prefixed URL, so firmware 0.1.1 and older also get the fast path without this update; 0.1.2 strips that prefix and re-measures direct, ghfast.top and gh-proxy.com.

`CMD:OTAPROBE` prints the three measurements and the selected route from a serial console connected to the OTA screen. The data partition is unchanged, so this release can be applied with device OTA alone.
