# 脆皮鸭 CPYOS 0.1.2

局部刷新、阅读功耗与更新加速。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 局部刷新与残影

- 键盘、设置、书库、阅读器面板、首页手写页与部分游戏改为**只驱动变化的条带**；进入界面、关闭面板和切屏仍是整页推送。
- 到期的残影清理**只清自上次清理以来变化的矩形**（默认开启，阈值 60%，并带 8 px 边缘外扩），不再每次都闪整屏。
- 显示设置拆成「定期全刷」（默认关）与「全刷间隔（页，5–120）」。快速翻页不再被单独限制为 5 页一次清理，设置值现在真实生效。
- 快速翻页改用 DU 波形，面板时间约 **150 ms**（原先约 360–500 ms）。

## 功耗与稳定性

- 阅读中**短按电源键**进入时钟待机并浅睡，再按回到原页；长按仍是关机。
- 8 秒没有推帧后关闭 SY7636A 高压轨，下一次推帧自动恢复。
- 只连网的页面退出时释放射频，不再让 STA 常驻。
- 修复空闲时 CPU 每 60 ms 在 240/80 MHz 之间抖动的问题。
- 修复横向重影的根因（一帧被两个 feeder 各启动一次），并为窗口推送加看门狗：扫描不返回时重启而不是死机。
- 阅读器快速点按不再被误判为长按选词。

## 显示与封面

- 封面缩略图改为 **8 位灰阶**，首页与书库使用 16 级画布；四个 Tab 之间切换不再整屏闪。
- 旧 `_g2` 缩略图路径自动迁移到 `_g8`，不再因找不到旧文件反复重绘。
- SD 卡读取失败时按 **40 → 20 → 10 MHz** 阶梯重试，边际卡不再直接落到「SD card error」。

## 更新

- OTA 固件改为从 **GitHub Release 资产**下载，并内置 **`ghfast.top`** / **`gh-proxy.com`** 两个镜像；先各取 32 KB 测速，再选最快线路，失败自动回退。
- 发布清单本身指向镜像，**0.1.1 及更早固件无需升级也能享受加速**。
- 阅读器状态栏新增「时钟更新」：**随翻页**（默认）或 **每分钟**。

★ **语言包键数 1576 → 1578**，数据分区有变化。只做设备 OTA（只写 app）会让 33 种语言因键数不符回退英文；请用完整安装包，或先用刷写脚本重写数据分区再升级。

## 安装与升级

设备 OTA：设置 → 系统 → 检查更新。首次安装 / 从 CrossMux 切换仍使用网页刷机的「首次安装 / 恢复」。

网页刷机：[yana-hangabina.github.io/cpyos](https://yana-hangabina.github.io/cpyos/#install)

## English

Partial refresh, lower reading power and faster updates for **Read Pico (RDP-G01-W)**.

**Partial refresh.** The keyboard, settings, library, reader panels, the two hand-rolled home screens and some games now drive only the strips that changed; entering a screen, closing a sheet and page switches still push a full page. The periodic clean now repaints only the rectangle that changed since the last clean (on by default, 60% union cap, 8 px dilation), so it no longer flashes the whole panel. Display settings split into **Periodic full refresh** (off by default) and **Full refresh every (pages, 5–120)**; fast page turns no longer get an extra 5-page cap. Fast turns keep the DU waveform and spend about **150 ms** of panel time instead of 360–500 ms.

**Power and stability.** A short power press while reading opens the clock face in light sleep; the next press returns to the same page, while a long hold still shuts down. The HV rails drop after 8 s without a frame and come back on the next push. Pages that only needed Wi-Fi release the radio on exit. Fixed the idle 240/80 MHz flip every 60 ms, the horizontal-smear root cause (one frame started twice), a scan watchdog for windowed pushes, and taps being misread as long-press selection.

**Display.** Thumbnails are now 8-bit gray and Home/library draw on a 16-level canvas, so switching tabs no longer flashes. Old `_g2` thumbnail paths migrate to `_g8`. A marginal SD card falls back through 40 → 20 → 10 MHz instead of failing with "SD card error".

**Updates.** OTA downloads the GitHub release asset and probes **ghfast.top** / **gh-proxy.com** with a 32 KB sample before choosing a route; the manifest itself is mirror-prefixed, so 0.1.1 and older also get the fast path. The reader status bar gains a **Clock updates** setting: **On page turn** (default) or **Every minute**.

The language pack changed from 1576 to 1578 keys. An app-only OTA leaves the old pack and makes the 33 packed languages fall back to English; use the full installer or reflash the data partition.
