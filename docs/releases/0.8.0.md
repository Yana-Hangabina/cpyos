# 脆皮鸭 CPYOS 0.8.0

Read Pico `0.8.0-rp` · Metalio E-INK4 Plus `0.8.0-e4p`

## 新增功能

### 阅读与 PDF

- 新增 PDF 支持：文字重排、目录、页码跳转、旋转、密码 PDF、书签、高亮与批注、批注导出；长按选词可查词或标注，坏页可跳过并重试。
- EPUB 排版支持更多 CSS：块级字号、强制分页、孤寡行、边框与底纹、首字下沉、小型大写字母、预格式化空白和复合选择器。
- 阅读设置新增行距、词间距、字间距和图片黑白模式，阅读字号范围扩大，侧按键可随屏幕方向翻转。
- 词典支持短语查词和候选回退，可把查词记录保存为词汇表；脚注选中改为描边高亮，返回后恢复原高亮和动作条。

### 阅读器与系统

- 长按电源先显示关机确认，确认后显示关机画面再断电；短按仍进入待机。
- 游戏改为插件：可在插件管理中安装、更新、删除和离线回退，也可从工具抽屉直接打开。
- 关于页新增显示屏控芯片名称和存储卡占用。
- 微信读书新增阅读时长同步（待实机验证）；付费或锁定章节改为占位页，不再中止整本缓存。
- 晋江文学城（闭源组件，随官方固件提供）新增网页会话导入、每日签到和多验证方式；原有书架、搜索、缓存、段评/章评、购买与云端进度继续提供（导入与签到待实机验证）。
- OPDS 与 KOReader 支持各两条自定义 HTTP 请求头；新增 Wi-Fi 空闲超时设置。

### Read Pico `0.8.0-rp`

- 新增 PDF 阅读，使用独立 PDF 引擎分区。
- 本次更换 PDF 分区布局，**必须使用完整安装包重新安装**；0.7.0 及更早版本不能通过普通 OTA 升级。完整安装后恢复后续 OTA。

### Metalio E-INK4 Plus `0.8.0-e4p`（首次发布）

- 适配 1216×684 墨水屏、触摸、三个侧键、电源键、4-bit SD、USB 串口与 U 盘、前光、扬声器与麦克风、触觉马达、电池计与充电状态、RTC、待机时钟与浅睡。
- 4G 已接入数据通路、SIM 状态与网络切换界面；本机未安装模块，实际联网待实机验证。
- 支持扬声器、麦克风和蓝牙音频；AI 语音、录音等依赖服务器或耳机的功能待实机验证。
- 前光支持亮度调节，并按厂商建议限制最高亮度。
- 提供书架、阅读器、PDF、浏览器、微信读书、晋江（闭源组件）、字体、WebDAV/Calibre、插件与游戏、计算器、阅读统计等完整应用。
- 电源支持电量百分比、充电状态页、待机时钟、浅睡和长按关机。
- CloudZao 设备绑定、资源推送和固件更新迁移到新 partner API：六位码绑定、资源下载与确认、OTA 检查已实机验证。

## 改进

- 同步 CrossMux 上游 2.0 排版与阅读改进：块级字号、分页与孤寡行、边框表格、首字下沉、small caps、CJK 断行、bidi 括号、标题不断词，以及按键重映射、OPDS 长按返回、KOSync 预设和插件总开关。
- 扩充越南、捷克、波兰、土耳其、希伯来、阿拉伯等界面字形；所选字体缺少某个字号时回退到系统可缩放字体；同一字族的界面字号共享字形数据，减少内存占用。
- 浏览器支持跟随阅读器的快速翻页、水波纹和刷新节律。
- 网络下载、Wi-Fi 释放、OTA 线路选择与超时处理更稳定；文件传输期间保持高频率运行。
- Plus 修正前光电流映射、快速翻页与水波纹设置持久化、Wi-Fi 自动连接与内存占用、截图方向和阅读统计缺字。
- 设置、弹窗、等待卡、购买抽屉和阅读器面板的交互与视觉统一。

## 修复

- 清除阅读或分页缓存不再删除标注、书签和阅读进度。
- 修正 EPUB 章节顺序、超长章节或超大字库打开失败、缺少封面、书库误收录字体/词典目录、替换字符不显示、标题被错误断词等问题。
- 修正电量百分比波动、高 DPI 电池图标风格、日期页重复电池图标，以及书签“高亮本屏”等文字被省略号截断。
- 修正设置项行数错位、大样式表被跳过、块底纹显示成竖条纹。
- 修正浏览器 `&nbsp;` 导致整行字体变小、链接下划线错位、分页导航无法翻章。
- 修正微信读书付费或试读章节中止整本、令牌过期、下载降频，以及网络恢复后异常复位、Wi-Fi 拆除崩溃、失败无原因提示。
- 修正晋江段评返回崩溃、批注删除后重新出现、跨页气泡重叠、取消登录需要多次返回。
- 修正长内容二维码版本计算错误、长按电源松手误进待机、残留文件句柄阻止休眠、WebDAV 私有目录访问等问题。

## 升级说明

- **Read Pico**：0.8.0 更换 PDF 分区，必须使用完整安装包；请勿使用 OTA 升级旧版本。发布页只提供完整安装入口，旧固件不会收到可安装的 OTA 镜像。完整安装后恢复后续 OTA。
- **E-INK4 Plus**：首次必须使用官网/发布页的完整安装包（写入分区表与数据分区，含阅读字库）；**CloudZao 固件市场的安装只写 app 分区，不能用于首次安装**。完成完整安装后，可在 CloudZao 获取后续应用更新；首次使用设备资源前需在新 partner API 中完成六位验证码绑定。
- 升级前建议备份 SD 卡和设备整片镜像；非中英文界面需要完整数据分区。
- 标记“待实机验证”的功能欢迎在发布后反馈。

## 已知限制

- Plus 本机没有 4G 模块和相机模组；SoftAP、深度睡眠和 BLE 翻页器配对尚不完整。
- CloudZao 首版需要平台审核；审核完成前设备可能查不到稳定版。
