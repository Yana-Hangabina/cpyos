# 脆皮鸭 CPYOS 0.8.1（Metalio E-INK4 Plus）

版本 `0.8.1-e4p`

## 新增

- **界面缩放**：设置 → 显示 → 界面缩放（100–125%），并逐屏修复 125% 下的四个主标签、设置、工具抽屉、找书与 Wi-Fi 面板排版。
- **Wi-Fi 稳定性**：射频命令串行化、保存网络静默重连、失败原因可读；空闲降频与面板推送不再互相干扰。
- **PDF 引擎解耦**：契约 v2（版本 / ABI / 主机服务表 / 布局键）。Plus 的引擎在 SD 卡上，布局未变，已安装的引擎继续可用。
- **阅读字体**：核心字体按字表分档（Plus 使用 8,105 字核心，约 1.64 MB）；界面字族补全标点与符号；字体扩展包支持 tier 声明。
- **电量**：状态栏电量胶囊每秒采样。

## 升级说明

- 已完成 0.8.0 完整安装的设备可直接更新；`cpyos-plus-0.8.1` 的完整安装包会写入应用两个槽、数据分区（语言包 / 核心字体）与 PDF 资源。
- CloudZao 固件市场的安装只写应用分区，不能用于首次安装；数据包请使用官网完整安装或设备内更新。

## 验证

- 构建与打包由 CI 完成；应用描述符必须为 `cpyos_metalio_plus` / `cpyos-plus-0.8.1`，`SHA256SUMS` 覆盖全部资产。
- 本机无第二台 S31 受影响，Plus 侧改动随本次同步的共享代码一起构建；界面缩放在 Plus 上与 Read Pico 使用同一套布局计算。
