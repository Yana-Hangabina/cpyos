# 脆皮鸭 CPYOS 0.1.1

0.1.0 之后的修复版本。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 修复

- **段评崩溃**：从段评面板返回时不再直接删除仍在运行的 worker；先等待请求结束再拆会话。若请求在 50 秒内仍不结束，宁可重启，也不在堆内部删除任务。
- **段评气泡**：气泡永远从段落最后一个字的右侧开始，并留在这一行的行盒内，可以借用右侧空白直到屏幕边缘；放不下时原地降级为纯数字或小圆点。段落跨页时只在真正段尾显示气泡。
- **段评正文**：一整条评论统一字号，长评论的换行不再裁掉单词。
- **首次阅读手势提示**：改为全屏区域图（左 / 中 / 右三块 + 右上角书签），长按、捏合、滑动等非区域动作以图标 + 文字列出；任意输入即可关闭并持久化。
- **Emoji**：内置 Noto Emoji 单色子集，按码位回退到 emoji 面；丢包或内存不足时只是没有 emoji，不会崩溃。
- **晋江章节序号**：过滤 `chaptertype != 0` 的哨兵条目，序号与站点一致；福利番外标记为「仅 App」，不再计入未购买。
- **网络稳定性**：三主机轮换时释放多余的 TLS 会话；握手期间保持 CPU 频率；段评任务降到空闲优先级，避免看门狗复位。

## 新增

- 下载范围页新增「同时缓存段评正文」开关（默认关）。整本缓存默认只取评论计数（气泡），打开后每章追加最多 30 秒 / 30 个请求的正文预取。

## 安装与升级

- **数据分区有变化**（语言包键数增加）。设备 OTA 只写固件，升级后请用完整安装包的「从 CPYOS 升级」重写数据分区；否则界面会回退英文、网页显示恢复页。
- 从 0.1.0 升级：网页刷机的「从 CPYOS 升级」，或在设备上 OTA 后再补写数据包。
- 从 CrossMux / 出厂固件切换：网页刷机的「首次安装 / 恢复」，会重建分区表并要求擦除芯片。**先做整片 16 MiB 备份。**

网页刷机：[yana-hangabina.github.io/cpyos](https://yana-hangabina.github.io/cpyos/#install)

## English

A bug-fix release after 0.1.0 for Read Pico. It fixes the comment-panel teardown crash, keeps paragraph-comment badges from overlapping any body text (including paragraphs that break across pages), unifies wrapped comment text on one font size, replaces the first-run hint with a full-screen touch-region map, adds an OFL Noto Emoji fallback, filters JJWXC chapter sentinels (so numbers match the site), marks app-only bonus chapters, and hardens the network path against watchdog resets. A new default-off toggle also caches comment bodies with bulk chapters.

The language pack gained keys, so after a device OTA rewrite the data partition with the **Upgrade from CPYOS** web installer. Back up the full 16 MiB flash before a first install.
