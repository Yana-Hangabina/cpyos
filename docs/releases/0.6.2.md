# 脆皮鸭 CPYOS 0.6.2

让「检查更新」优先直连 GitHub，并缩短线路切换的等待时间。基于 0.6.1，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 改进

- **GitHub 优先**：检查更新先直连 GitHub，失败后才依次尝试镜像与 Pages，每条线路都有独立超时。
- **线路更少**：固件下载最多只测试三条线路，不再逐条尝试全部镜像。
- **数据包复用线路**：语言与资源包使用刚成功的线路，失败时才切换。
- **“暂无更新”更快**：日常检查在正常情况下明显缩短。

## 升级说明

- 0.6.0 / 0.6.1 可直接在设备内 OTA；数据包与 0.6.1 相同。
- 0.2.1 及更早版本请用官网网页刷机升级一次。

## English

Makes update checks try GitHub first and shortens the route fallback. Based on 0.6.1, for **Read Pico (RDP-G01-W)**.

**Improved.** The check connects to GitHub first, then tries mirrors and Pages only if that fails, each with its own timeout. Firmware downloads probe at most three routes instead of every mirror. Language and resource packs reuse the route that just worked and switch only on failure. A routine "no update" check is noticeably faster.

**Upgrade.** 0.6.0 and 0.6.1 can use device OTA; the data packs are unchanged from 0.6.1. Devices on 0.2.1 or older need the website flasher once.
