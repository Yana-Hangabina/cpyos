# 脆皮鸭 CPYOS 0.2.3

中文搜索、文字设置稳定性与字体显示的修复。基于 0.2.2，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 修复

- **晋江中文搜索**：修复书名与作者搜索的乱码、标题里出现多余标签，以及中文作者名搜不到的问题；搜索结果现在会继续翻页。
- **文字设置卡死**：离开文字设置页不再导致整机无响应；渲染锁增加了自我保护，异常加锁不会再冻结界面。
- **极端情况下的整页刷新卡死**：整页刷新也纳入超时保护，异常时自动恢复，不再永久停住。

## 改进

- **字体设置更省内存**：设置页预览使用更小的字形缓存，离开页面后释放，不会把预览状态带进阅读器。
- **文字设置预览**：可在 1 位与 16 级之间切换预览，效果与下一次翻页一致；1 位预览移动选项时不再整屏闪烁。
- **字重显示**：伪粗体与专注阅读在各类字体上都按同一规则加粗，不再出现“只有个别字母变粗”。
- **卡死诊断**：界面无响应时自动记录任务与锁状态，便于定位问题。

## 升级说明

- 数据包与 0.2.2 相同，设备 OTA 只需更新系统；中文与英文界面完整。
- 0.2.2 及以后可直接在设备内 OTA；0.2.1 及更早版本请用官网网页刷机升级一次。

## English

Chinese search, text-settings stability and font-display fixes. Based on 0.2.2, for **Read Pico (RDP-G01-W)**.

**Fixes.** JJWXC book and author search no longer produce garbled titles or stray tags, and Chinese author names can be found again; results continue across pages. Leaving the text-settings page no longer freezes the device, and the render lock now protects against accidental re-entry. Full-page refreshes also get a timeout and recover instead of hanging forever.

**Improved.** The text-settings preview uses a smaller glyph cache and releases it on exit, gains a 1-bit / 16-level toggle that matches the next page turn, and no longer redraws the whole screen on each selection. Bold and focus-reading weights follow one rule across font families. A freeze now records task and lock state for diagnosis.

**Upgrade.** The data packs are unchanged from 0.2.2, so device OTA only updates the system; Chinese and English stay complete. 0.2.2 and newer can use device OTA; devices on 0.2.1 or older should use the website flasher once.
