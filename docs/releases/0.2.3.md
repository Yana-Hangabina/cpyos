# 脆皮鸭 CPYOS 0.2.3

晋江中文搜索、字体设置稳定性与字体重量的修复，基于 0.2.2。面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 修复

- **晋江中文搜索乱码**。站点的 GB18030 页面会按字节把关键词回显到 `<title>` 和每条结果的标题高亮里。此前固件发送 UTF-8 字节，整页因此既不是合法 UTF-8 也不是合法 GBK：作者名显示为 U+FFFD 菱形问号或方框，高亮标签从多字节字符中间切断后，`</span>` 会作为字面文本进入标题。现在书搜索与高级搜索的关键词都按 **GBK** 编码发送；`JjwxcWapShelf::copyText` 也只复制真正存在的续字节，标签会被正常跳过。
- 中文 **作者搜索**（`t=2`）恢复可用：站点按 GBK 字节匹配，UTF-8 关键词此前返回"暂无搜索结果"。搜索现在会跟随分页，最多 12 页 / 300 条。
- **离开「文字设置」整机卡死**。`onExit()` 在 `ActivityManager` 已持有渲染锁时再次加锁，非递归互斥量永久阻塞，且死在日志之前，表现为屏幕不动、只能断电。已移除该加锁；渲染锁新增同任务递归保护，命中时只记录 `RLCK` 错误并当作 no-op。
- **整页推屏也纳入扫描看门狗**。此前只有区段/列带推送有 8 秒看门狗；全页推送若因面板门环锁死而永不返回，UI 会永久阻塞。现在所有同步推屏入口超时后自动重启并留下 `SCANWD` 日志。

## 改进

- **字体内存预算**：文字设置页只画一段示例文字，阅读矢量字面因此按 **128 KB / 512 字形**加载（正常阅读仍是 1 MB / 4096），流式读取前缀从 1 MB 降到 256 KB。同一字族常驻上限 4 MB，PSRAM 最大连续块不足 512 KB 时跳过额外的 UI 回退面。离开设置页会同时卸载矢量字面，预览的小缓存不会再带进阅读器。
- **文字设置页**：标签条右侧新增「快速翻页」预览开关，示例文字在 **1 位**与 **16 级**之间切换，和阅读器下一次翻页的实际渲染一致；切到 16 级会自动打开抗锯齿。1 位预览走列带刷新，移动选择不再整屏闪；列表滚到底时卡片底边正确收口。
- **字重规则统一**：伪粗体对所有字形生效；专注阅读（bionic reading）在只有单一字样的 `.cpfont` 字族上也显示 1 px 合成加粗；伪粗体与专注阅读叠加时，强调不会被压成同一档。
- **自动卡死取证**：主循环心跳停止 10 秒后，后台任务会打印所有任务状态与渲染 / 存储 / 电源互斥量的持有者（`STUCK`），下次卡死无需复位即可从串口日志定位。

## 升级说明

- 数据分区五个 blob（`pinyin.dat`、`web_pack.dat`、`hyphen.dat`、`i18n_pack.dat`、`emoji.dat`）与 0.2.2 相同，**设备 OTA 只写 app 分区**即可；中文界面完整，其余 33 种语言不受影响。
- 0.2.2 及更新版本可直接在设备内 OTA。
- ★ **0.2.1 及更早版本请用官网网页刷写升级**：这些版本的 OTA 清单仍在 GitHub Pages，部分网络无法访问，设备会一直检查失败或极慢。升级一次后即可正常使用设备 OTA。

## English

Search, font-settings stability and font-weight fixes, based on 0.2.2, for **Read Pico (RDP-G01-W)**.

**Fixes.**
- **JJWXC Chinese search mojibake.** The GB18030 page echoes the query bytes into its title and into a highlight span inside every result. Sending UTF-8 made the page valid as neither encoding: author names showed as U+FFFD diamonds or tofu, and a highlight span that cut a multi-byte character in half left a literal `</span>` in the title. Book and advanced search now percent-encode the query in **GBK**, and `JjwxcWapShelf::copyText` copies only continuation bytes that are really present, so markup is skipped instead of being swallowed. Chinese author search (`t=2`) works again, and search follows the pager up to 12 pages / 300 rows.
- **Leaving the text-settings sheet froze the device.** `onExit()` took the render lock again while `ActivityManager` already held it; the non-recursive mutex blocked forever before the exit was even logged. The extra lock is gone, and a same-task recursive lock is now a logged no-op (`RLCK`).
- **Full-page pushes now use the scan watchdog.** Previously only windowed/banded pushes had the 8 s watchdog. If a full-page scan never returned, the UI stayed blocked and the board has no reset button. Every synchronous push now restarts the firmware on timeout and leaves a `SCANWD` line.

**Improvements.**
- **Vector-font memory budget.** The text-settings preview loads the reader face with a **128 KB / 512-glyph** cache (reading stays at 1 MB / 4096) and a 256 KB streaming prefix. A family is capped at 4 MB resident, UI fallback faces are skipped below a 512 KB PSRAM block, and leaving the sheet unloads the vector face so the preview cache does not leak into the reader.
- **Text-settings sheet.** A fast-page-turn switch on the tab bar previews **1-bit** versus **16-level** text exactly as the reader will draw the next page; 16-level also enables anti-aliasing. The 1-bit preview uses banded pushes, the card border closes correctly at the end of the list.
- **One font-weight rule.** Fake bold now thickens every glyph; bionic reading shows a 1 px synthetic bold on single-style `.cpfont` families too; combining the two no longer flattens the emphasis.
- **Stuck-state capture.** If the main loop heartbeat stops for 10 s, a background task prints every task state plus the render/storage/power mutex holders (`STUCK`), so the next freeze can be diagnosed without a reset.

**Upgrade notes.** The five data blobs are unchanged from 0.2.2, so device OTA can write only the app partition; the Chinese UI stays complete and the other 33 packed languages are unaffected. 0.2.2 and newer can update on the device. ★ **0.2.1 and older should use the website flasher**: their OTA manifest still lives on GitHub Pages, which some networks cannot reach.
