# 脆皮鸭 CPYOS 0.8.2

Read Pico `0.8.2-rp` · Metalio E-INK4 PLUS `0.8.2-e4p`

本次是字体与数据包的收口版本，阅读、PDF 与应用功能没有变化。

## 字体

- **两设备统一预装 3,500 字阅读核心**。8,105 字核心改为可选的「中文扩展」
  （扩展字体页，家族 `CPYOSCJKCore`，就地在原路径上升级），遇到缺字时下载即可。
  这样两台设备的字体语义一致，扩展包也不再出现“某台设备预装了它、所以看起来没用”的情况。
- **UI 字面覆盖补齐**：字体扩展页的包名（如「多语言文字（韩泰阿希梵越）」）里的用字并入
  系统 UI 字面，包名不再出现方框；新增回归测试，今后包名超出 UI 字面会直接失败。

## 数据包与升级

- **修复「仅更新数据包」取错核心**：包清单曾按别名 `cjk_core.dat` 请求，而发布包里是
  `cjk_core_3500.dat`；数据包属可选，下载落空会被静默跳过。现在包清单的每个名字**就是**
  发布包里的文件名，打包时逐行比对。
- 两个设备的数据包内容一致（语言包、拼音、断词、emoji、Web 资源与核心字面同源同字节），
  因此继续共用同一组发布资产。

## 升级说明

- 0.8.1 及以后的设备可直接 OTA（应用 + 数据包）。0.7.0 及更早版本仍需完整安装。
- 本次不改变分区表、PDF 引擎契约与语言包键集合；已安装的 PDF 引擎继续可用。
- Metalio Plus 经 CloudZao 市场更新只写应用分区；数据分区请使用官网完整安装或设备内更新。

## 验证

- 发布前：`verify_release_artifacts --release`、数据清单与六个数据包头、`SHA256SUMS`。
- 两设备的 `cjk_core.dat` 由同一策略产出（3,500 档，642,887 B），发布包只保留一份。
