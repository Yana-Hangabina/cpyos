# 脆皮鸭 CPYOS 0.1.0

第一个公开版本。基于 CrossMux 1.6.5，面向 **Read Pico（小纸 Pico，RDP-G01-W）**。

## 新增

- **新版界面 / refreshed UI**：首页、书架、找书、我的重新排版；设置从「我的」进入分类子页并原路返回。
- **晋江文学城原生客户端**：书架、发现、搜索、收藏夹、章节购买、段评点赞与回复、阅读进度同步；免费章走 App API，VIP 章走 WAP 解密链。
- **微信读书**：扫码登录、书架、EPUB 下载与离线阅读、进度同步，与本地书和晋江书共用书架。
- **中文阅读**：离线拼音输入与书名搜索、11 种语言断词、GB2312 兜底、SD 卡 TTF/OTF/TTC、EPUB 内嵌字体。
- **显示与翻页**：水波纹翻页、黑白快速翻页、状态栏时钟局部刷新、屏幕修复、倾斜 / 摇晃体感翻页。
- **阅读器**：书签、批注、词典、阅读统计、续读卡、KOReader 进度同步。
- **系统**：设备 OTA、浏览器传书、WebDAV、OPDS、Calibre 无线、33 种 UI 语言；成品 EPUB 与章节缓存使用设备绑定密钥加密。

## 安装

- **首次安装 / 从 CrossMux 1.6.5 切换**：使用网页刷机页的「首次安装 / 恢复」。它会重建分区表并要求擦除芯片，**请先做整片 16 MiB 备份**。
- **从 CPYOS 升级**：使用「从 CPYOS 升级」，保留 NVS 和分区表。
- **设备 OTA**：安装 0.1.0 后，设置 → 系统 → 检查更新。

网页刷机：[yana-hangabina.github.io/cpyos](https://yana-hangabina.github.io/cpyos/#install)

## 已知事项

- 预编译包只面向 Read Pico；其它 CrossMux 目标请从源码构建。
- 晋江、微信读书使用非公开接口，设备侧 TLS 不校验证书与主机名，请只在可信网络使用。
- 首次安装会清除设备上的 Wi-Fi 凭据；SD 卡里的书和 `/.crosspoint` 设置不受影响。

## English

The first public release of 脆皮鸭 CPYOS for Read Pico, based on CrossMux 1.6.5. It adds a refreshed UI, native JJWXC and WeRead clients, Chinese input and fonts, water-ripple and motion page turns, device OTA, and device-bound encryption for packaged books and cached chapters.

Back up the full 16 MiB flash before a first install. Use **First install / recovery** when coming from factory firmware or CrossMux 1.6.5, and **Upgrade from CPYOS** for an existing CPYOS installation. After 0.1.0, update on the device via **Settings → System → Check for updates**.

Unofficial firmware. JJWXC and WeRead endpoints may change; device TLS does not verify the server certificate. Use a trusted network.
